The Post-Trainer's Guide for Multilingual Synthetic Data Generation

By generating over 1.4M synthetic examples from 10 teacher models, and training over 240 student models, we study the multilingual synthetic data pipeline and distill it into a recipe.

High-quality training data is often scarce for less-resourced languages, and collecting it from native speakers demands substantial human effort, creating a bottleneck for language-specific model development. To alleviate this challenge, synthetic data generation has gained traction as a promising solution: a typically larger teacher model generates training examples, which are then used to finetune a smaller student model to replicate the knowledge of the teacher.

In this work, we study the key design decisions in the synthetic data pipeline: which teacher model to use, which data generation method to apply, and how these choices play out across languages. Based on our findings, we recommend a recipe for generating multilingual synthetic data.

The synthetic data pipeline. Given a seed dataset, a teacher model synthesizes prompt–response pairs to form a synthetic dataset. Supervised finetuning on a base model results in a student model that learns from the teacher-generated outputs.

Polyglot Score. Given a teacher model, we then measure (1) the intrinsic quality of the synthetic dataset and (2) the extrinsic performance of a student model trained on that data across a diverse set of multilingual tasks. Our evaluation framework is holistic, as it considers these two output artifacts. We find this to be important as synthetic datasets enter the data commons (which are reused later on), and student models are deployed in real-world applications.
